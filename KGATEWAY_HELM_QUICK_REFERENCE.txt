KGATEWAY HELM VALUES - QUICK REFERENCE CARD

MINIMAL HELM VALUES TO ENABLE AGENTGATEWAY + AI EXTENSION:
================================================================================

# Helm values structure
agentGateway:
  enabled: true
gateway:
  aiExtension:
    enabled: true

# Helm CLI command
helm upgrade -i -n kgateway-system kgateway \
  oci://cr.kgateway.dev/kgateway-dev/charts/kgateway \
  --set agentGateway.enabled=true \
  --set gateway.aiExtension.enabled=true \
  --version v2.1.1

OPENTELEMETRY TRACING CONFIGURATION (NOT HELM VALUES)
================================================================================

Configured via GatewayParameters CRD:

spec:
  kube:
    aiExtension:
      tracing:
        enabled: true
        endpoint: "http://opentelemetry-collector.telemetry.svc.cluster.local:4317"
        sampler:
          type: "traceidratio"        # alwaysOn, traceidratio, parentbased_*
          arg: "1.0"                  # 1.0 = 100%, 0.1 = 10%
        protocol: "grpc"              # grpc or http
        transportSecurity: "plaintext" # tls or plaintext
        timeout: 10000                # milliseconds

================================================================================
INSTALLATION CHECKLIST
================================================================================

1. Install Gateway API CRDs (prerequisite):
   kubectl apply -f https://github.com/kubernetes-sigs/gateway-api/releases/download/v1.4.0/standard-install.yaml

2. Install kgateway CRDs:
   helm upgrade -i --create-namespace --namespace kgateway-system \
     --version v2.1.1 \
     kgateway-crds oci://cr.kgateway.dev/kgateway-dev/charts/kgateway-crds

3. Install kgateway with agentgateway + AI extension:
   helm upgrade -i -n kgateway-system kgateway \
     oci://cr.kgateway.dev/kgateway-dev/charts/kgateway \
     --set agentGateway.enabled=true \
     --set gateway.aiExtension.enabled=true \
     --version v2.1.1

4. Deploy GatewayParameters (if using OpenTelemetry):
   kubectl apply -f gateway-parameters-otel.yaml

5. Verify:
   kubectl get gateway -n kgateway-system
   kubectl get pods -n kgateway-system
   helm get values kgateway -n kgateway-system -o yaml

================================================================================
KEY HELM VALUES EXPLAINED
================================================================================

agentGateway.enabled: true
  - Enables agentgateway integration for agent connectivity
  - Supports Agent-to-Agent (A2A), MCP, REST APIs
  - Managed by kgateway control plane

agentGateway.enableAlphaAPIs: false
  - Set to true for alpha features (Waypoint, etc.)
  - Not recommended for production

gateway.aiExtension.enabled: true
  - Enables AI Gateway extension for LLM routing
  - NOTE: Deprecated for Envoy proxies, use agentgateway instead
  - Removed in kgateway v2.2

================================================================================
OPENTELEMETRY SAMPLER TYPES
================================================================================

alwaysOn
  - Sample 100% of traces
  - Use for: Development, debugging, critical systems
  - Performance impact: High

alwaysOff
  - Sample 0% of traces
  - Use for: Disabling tracing
  - Performance impact: None

traceidratio
  - Sample percentage based on trace ID hash
  - Use for: Production systems with adjustable sampling
  - Config: arg "1.0" = 100%, "0.1" = 10%
  - Performance impact: Configurable

parentbased_traceidratio
  - Best for distributed systems
  - Inherit parent span sampling decision
  - Fallback to traceidratio if no parent

parentbased_alwaysOn
  - Always sample if parent is sampled
  - Ensures distributed trace integrity

================================================================================
OTLP ENDPOINTS AND PORTS
================================================================================

gRPC (recommended):
  - Endpoint: opentelemetry-collector.telemetry.svc.cluster.local:4317
  - Protocol: grpc
  - Certificate validation: yes

HTTP:
  - Endpoint: opentelemetry-collector.telemetry.svc.cluster.local:4318
  - Protocol: http
  - Lower performance than gRPC

IMPORTANT BREAKING CHANGES
================================================================================

GatewayParameters field name change (recent versions):

OLD (DEPRECATED):
  spec:
    kube:
      agentGateway:  # PascalCase
        enabled: true

NEW (CURRENT):
  spec:
    kube:
      agentgateway:  # lowercase
        enabled: true

================================================================================
AI GATEWAY DEPRECATION
================================================================================

AI Gateway for Envoy-based proxies:
  - Status: DEPRECATED in kgateway v2.1.1
  - Removal: Planned for kgateway v2.2
  - Replacement: Use agentgateway instead
  - Recommendation: Migrate to agentgateway for new deployments

agentgateway:
  - Status: Fully supported and actively developed
  - Recommended for: New AI/agent deployments
  - Features: AI routing, agent connectivity, MCP support, tracing
