# Implementation Plan: Feature Flagging System

**Branch**: `115-feature-flags` | **Date**: 2025-12-29 | **Spec**: [spec.md](./spec.md)
**Input**: Feature specification from `/specs/115-feature-flags/spec.md`

## Summary

Deploy a CNCF-compliant feature flagging system using OpenFeature/flagd for flag evaluation and Flipt for UI/management. The architecture uses a centralized flagd deployment (ClusterIP service) with Flipt providing GitOps-native flag management and a web UI. Integration includes Keycloak SSO, External Secrets for credentials, Tailscale for remote access, and OpenTelemetry for observability.

## Technical Context

**Language/Version**: TypeScript (CDK8s charts), Go (flagd/Flipt containers)
**Primary Dependencies**: CDK8s, OpenFeature Operator, flagd v0.10+, Flipt v2
**Storage**: Git repository (flag configurations), ConfigMaps (runtime flags)
**Testing**: ArgoCD sync validation, flagd health probes, integration tests
**Target Platform**: Kubernetes (KIND local, Talos production)
**Project Type**: Infrastructure/Platform (CDK8s charts)
**Performance Goals**: 1000 flag evaluations/second/pod, <10ms p99 latency (per SC-003)
**Constraints**: <30s flag propagation (SC-004), graceful degradation during UI outage (SC-006)
**Scale/Scope**: All existing services (Backstage, CAIPE agents, Keycloak plugins)

## Key Integration Points

### Keycloak SSO (FR-004)

- Flipt configured with OIDC authentication
- Realm: `cnoe` (existing)
- Client: `flipt` (new, confidential)
- Role mappings for RBAC (FR-015):
  - `developer`: read/write dev/staging
  - `platform-team`: read/write all environments

### OpenTelemetry (FR-008)

- flagd native OTLP exporter enabled
- Traces: Flag evaluation spans with context
- Metrics: Evaluation count, latency, errors
- Collector: `otel-collector.observability.svc`

### Git Backend (FR-009)

- Repository: `feature-flags` (Gitea/GitHub)
- Branch per environment or directory structure
- ArgoCD sync for infrastructure, Flipt sync for flags
- Webhook notifications for real-time updates

## SDK Integration Examples

### Go Application

```go
import (
    "github.com/open-feature/go-sdk/pkg/openfeature"
    "github.com/open-feature/go-sdk-contrib/providers/flagd/pkg/provider"
)

func init() {
    flagdProvider := provider.NewProvider(
        provider.WithHost("flagd.feature-flags.svc.cluster.local"),
        provider.WithPort(8013),
    )
    openfeature.SetProvider(flagdProvider)
}

// Usage
client := openfeature.NewClient("my-service")
darkMode, _ := client.BooleanValue("dark-mode-enabled", false, openfeature.EvaluationContext{})
```

### TypeScript Application

```typescript
import { OpenFeature } from '@openfeature/server-sdk';
import { FlagdProvider } from '@openfeature/flagd-provider';

OpenFeature.setProvider(new FlagdProvider({
  host: 'flagd.feature-flags.svc.cluster.local',
  port: 8013,
}));

const client = OpenFeature.getClient('my-service');
const darkMode = await client.getBooleanValue('dark-mode-enabled', false);
```
