  IdpBuilder expects packages in this exact structure:
  dist/
  ├── <app-name>.yaml              # ArgoCD Application (required)
  └── <app-name>/                  # Package directory
      └── manifests/               # Manifest directory
          ├── <resource>.yaml      # Individual K8s resources
          ├── <resource>.yaml
          └── kustomization.yaml   # Auto-generated resource list

  1. Top-level ArgoCD Application YAML with example: basic label (IdpBuilder requirement)

  3. manifests/ subdirectory containing resources
